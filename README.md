# Alexpapa 시험콕 V12 · Study OS

사용자가 제공한 V11을 기반으로 수정한 V12입니다. Express 서버, 쿠키 로그인, Supabase Auth·student_states·Storage, 로컬 개발 저장과 기존 `/api/analyze`를 유지합니다.

## 사용 흐름

- 홈 과목 → 학습 허브 → 최근 공부·이어서 공부·최근 자료·오답·AI튜터·유사문제.
- 공부노트에서 과목 → 단원 → 자료를 선택하고 제목·문제 내용을 검색합니다. V11 자료는 `sub_subject`를 단원으로 사용합니다. 노트의 **분류 수정**에서 직접 정정할 수 있습니다.
- 튜터의 **과목 전체 / 현재 자료 / 문제 선택**으로 대화방을 전환합니다. 메시지는 기존 계정의 `tutorThreads`에 보관합니다. 작성 중인 질문도 대화방별로 분리합니다.
- 답·해석·분석 방향은 접힌 **추가 옵션** 안에 있습니다. 영어 독해는 내 해석, 수학·국어 문제는 내 답/풀이를 조건부 표시합니다. 암기자료에는 답 입력을 표시하지 않습니다. 숨겨진 입력은 전송하지 않습니다.
- 수학은 원본, AI 재구성 그림, 개념·원리, 단계별 풀이, 핵심 요점, 오답 교정, 이해 확인, 난이도별 유사문제를 같은 노트에서 보여줍니다.
- 국어 문단 해설·숨은 의미·문제 검토, 영어 번역·해석 오류·단어·문법, 암기과목 요점·암기를 유지하고 기존 `quiz`를 화면에 표시합니다.

## 수학과 설명의 근거

개념의 뜻 → 공식의 이유/유도 → 문제 조건과 연결 → 단계별 식과 설명 → 원래 조건에 대입한 검산 순서로 AI 설명을 요청합니다. 설명의 `evidence`와 풀이의 `source_basis`에 근거를 기록합니다. 읽기 어려운 좌표는 임의 수치로 채우지 않고 확인 필요로 표시합니다.

`math_scene`은 점, 일반형 직선(수직선 포함), 이차함수, 원, 다각형, 선분, 주석을 담습니다. SVG의 x/y 단위 길이는 같게 유지합니다. 수치가 없거나 축 범위가 유효하지 않으면 재구성을 보류합니다. V11의 단일 그래프도 변환해 재사용합니다.

**원본 / AI 재구성 / 새로 만든 유사문제**를 구분합니다. 좌표가 없는 도형을 임의 좌표로 정답처럼 재현하지 않습니다. AI 정확도를 코드가 보증하지는 않으며, 근거 표시·불명확성 안내·검산 요청으로 확인할 수 있게 설계했습니다.

## 분석 재사용과 저장

파일 내용·이름·형식과 과목·방식·유형·학생 입력·추가 요청·단원·모델·V12 스키마를 SHA-256 키로 묶습니다. 같은 계정의 동일 요청은 저장된 분석을 반환하고 AI 업로드를 생략합니다. 동시 동일 분석도 한 번만 수행합니다. 결과를 서버에서 먼저 저장하여 탭을 닫아도 완료된 자료가 자료함에 남습니다.

튜터는 원본을 다시 보내지 않고 선택한 방의 최근 대화와 저장된 분석을 사용합니다. 과목 전체 방에는 다른 자료나 과목의 대화를 자동으로 넣지 않습니다. 동일 튜터 문맥/질문 캐시는 최대 1시간·500건이며 재시작 시 초기화됩니다. 분석 캐시는 `studyItems`에 저장해 재시작 후에도 남습니다. 429 응답은 대기시간을 안내하고 자동 반복 요청을 하지 않습니다.

기존 분석·exam·materials·ai 등 알 수 없는 상태 필드도 삭제하지 않습니다. SQL 변경은 없습니다. V11 화면 대화는 원래 저장되지 않아 복원할 기록이 없고, V12 대화부터 저장됩니다. 실패 시 **저장 실패 · 재시도**를 표시합니다. 여러 기기의 동시 편집 병합은 기존 전체 상태 저장 방식과 같습니다.

## 실행과 검증

Node.js 20 이상에서 `npm ci`, `npm start`를 실행합니다. 실제 API 사용은 `.env.example` 변수들을 본인 환경에 맞춰 설정합니다. 로컬 개발에서는 Supabase 변수들을 비워두면 `data/`에 저장합니다. production은 기존처럼 Supabase와 SESSION_SECRET이 필수입니다.

`npm test`는 임시 계정·저장소와 모의 OpenAI 응답으로 인증·캐시·저장·대화 문맥·원본 권한·429 처리를 검사합니다. `tests/mock-openai.mjs`는 테스트에서만 사용하고 `npm start`에서는 불러오지 않습니다.

[DEPLOY_RENDER_KO.md](DEPLOY_RENDER_KO.md)에 배포 안내, [VALIDATION_KO.md](VALIDATION_KO.md)에 검증 범위와 파일 구조가 있습니다.

## V12 그래프 보완판 (1.2.1)

비어 있는 math_scene이 기존 그래프를 가리지 않도록 유효한 결과를 선택합니다. 수학 세부 과목도 수학 노트로 엽니다. 기존 노트에 그래프가 없으면 **원본으로 그래프 만들기**로 그림 정보만 추출하고 저장합니다. 다시 열 때 결과를 재사용합니다. 튜터의 **그래프로 설명**은 저장된 문제 조건 또는 질문에 명시한 식·좌표로 그림과 설명을 함께 생성해 대화방에 저장합니다. 수학 자료별 질문은 가능한 경우 그림을 함께 만들고, 과목 전체의 일반 질문은 기존 텍스트 응답을 사용합니다. 원본 조건이 부족하면 임의 그림을 만들지 않고 확인 필요를 안내합니다.
