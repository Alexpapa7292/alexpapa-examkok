# Alexpapa 시험콕 V11 · Study OS

V11은 기존의 '자료를 올리고 요약을 보는 앱'에서 **실제로 공부하는 흐름** 중심으로 재설계한 버전입니다.

## 핵심 변화
- 핸드폰: 카메라로 문제/교과서/필기 촬영 → 바로 분석
- 태블릿: 노트형 공부화면 + 오른쪽 AI 튜터
- 자동 과목/자료 유형 판별
- 국어: 본문 한 장씩 설명, 숨은 의미, 문제풀이/오답 핵심
- 수학: 개념·원리, 풀이 진단, 직선/이차함수/원 그래프 시각화, 난이도별 유사문제
- 영어: 학생 해석 분석, 어색한 부분, 취약 단어, 문장 안 문법
- 한국사/사회/과학 등: 쉬운 설명 + 요점 + 반드시 암기 + 시험 포인트
- 기본 과목: 국어, 수학, 영어, 한국사, 사회, 과학, 정보, 제2외국어, 한문, 진로/선택, 기타
- 과목 추가 가능
- 원본은 최초 분석 때만 AI가 읽고, 이후 AI 튜터는 저장된 압축 공부노트만 사용하여 토큰 사용량 절감

## 배포
기존 V10.1과 동일하게 GitHub 저장소 루트에 압축을 풀어 덮어쓰고 Render에서 최신 커밋을 배포합니다.
